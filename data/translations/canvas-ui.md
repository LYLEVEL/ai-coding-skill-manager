# Canvas界面

Canvas UI 是一个开源的框架无关“创意画布”组件库。每个元素都渲染**真实的、仍然可交互的HTML**（文本保持可选择，链接保持可点击），画布元素中实时运行WebGL或WebGPU着色器效果——流体模拟、火焰、玻璃折射、粒子溶解、故障、ASCII等。大多数特效使用实验性的“画布内html”浏览器API来读取并重绘实时DOM作为GPU纹理;在不支持该 API 的情况下，组件会优雅地退回到纯 HTML 或 WebGL 覆盖层，因此其他访客不会出错。

组件不是 npm 依赖——它们通过兼容 shadcn 的注册表分发，安装后会将单个类型化的源文件（'components/canvasui/...'）复制到项目中，开发者随后拥有并自由编辑。

## 何时该拿起这个

把它当作**一个刻意英雄时刻**的工具，而不是通用的UI套件——这正是前端设计技能中描述的“把你的勇气集中在一个地方”的领域。

适合的：
- 一个着陆/营销页面的英雄、作品集文章、产品发布页面、关于/宣言页面
- 一个令人难忘的互动瞬间（卷轴揭示、光标跟随的花哨、空状态或带有个性的404）
- 以触感和高端感受为重点的原型或音高

不合适的——如果被问及时，避免或明确指出权衡：
- 用户在实际工作中会反复盯着任何界面——GPU 着色器效果在实时内容上是新奇的，且容易让人疲劳
- 任何必须在不同浏览器间可靠运行的现状：完整的画布内HTML体验目前需要Chrome/Edge 140+在标志或Origin试用令牌后面;其他地方则是WebGL专用的备份或纯HTML格式
- 表单、表格或任何内容，用户需要精确选择/复制文本——因画布层位于真实DOM之上，需逐案验证行为

## 组件目录（24个组件）

按效果族分组，这样你就能根据前端设计的“主题选择”原则，为简报主题选择合适的纹理：

**流体/液体/玻璃（触感、高端、产品发布感）**
- “Liquid”——基于实时HTML的指针驱动GPU流体仿真
- “气泡”——沿光标移动的玻璃状水滴，通过元球折射页面
- “玻璃”——光标跟随的玻璃镜头，折射和变焦如水晶球
- “玻璃物体”——任何以漂浮液态玻璃（折射、色散、霜）渲染的3D模型/SVG/图像
- “液体物体”——一个3D模型/SVG/图像拖曳在隐形液体中，将光线分解为颜色
- “霜冻”——冰面，在光标下方融化后再次冻结
- “水滴”——雨滴沿屏幕流下，折射下面的HTML内容
- “Clouds”——主题感知的雾气，模糊/折射HTML，被光标风分开
- “涟漪”——水波从点击声中扩散，折射着页面如同池塘

**火焰/能量（大胆、高能量、发射/CTA时刻）**
- “Blaze” — 火花、烟雾、热量失真在实时HTML上升起
- “火焰缠绕”——用熔融边缘和火花包裹任何元素的火焰边框
- “力场”——能量护盾，点击器引爆折射冲击波

**粒子/溶解/揭示（优雅过渡，剖面揭示）**
- “粒子揭示”—— HTML 以细颗粒形式渲染，合并成靠近光标的清晰界面
- “粒子滚动”—— HTML在一行下方溶解为沙粒，沙粒在滚动时重新组装
- “粒子对象”——一个3D模型/SVG/图像，重建为散射后弹回的粒子
- “Shatter”—— HTML分解成3D玻璃碎片，带着柔和阴影进行浮游/折射
- “剥离”——HTML 在悬停时从选定的边缘剥离，露出下面的一层
- “激光”——靠近视口底部的激光束，在滚动时从其背后显示 HTML

**复古/故障/模拟质感（编辑感、俏皮、品牌前导）**
- “故障”——广播故障突发、RGB分裂、块损坏
- “VHS”——磁带播放磨损：波形、头部切换噪音、色度泄漏、颗粒感
- “复古抖动”——复古抖动镜头，将 HTML 像素化绕过光标
- “解密揭示”——HTML以ASCII密文形式渲染，解密后在光标附近清晰的界面中解密
- “画布”——在编织艺术家画布上绘制HTML并用光标拖拽湿润的颜料脊线
- “布”——HTML悬挂在风波纹布上，光标在布料上发送波纹

**ASCII / 抖动对象渲染（3D资产展示）**
- “ASCII 对象” / “抖动对象” / “墨水对象” — 在工作室场景中分别以形状匹配 ASCII、1位抖动或手工印刷墨水渲染的 GLB/glTF 模型、SVG 或图像
- “ASCII 扫描”——发光的 ASCII 带在文本行间扫过，将一个内容集交换到另一个
- “Asciify” — 一种光标跟踪镜头，可在其下方重新绘制实时 HTML ASCII

**结构/布局扭曲**
- “弯曲”——将实时HTML的顶部/底部折叠在虚拟边缘上，就像在立方体面上滚动一样
- “网格”——围绕光标呈错落波纹的3D瓷砖
- “Hex Float” — 用于带有透视倾斜和光标抬起功能的闪亮浮动六边形瓦片上的HTML
- “位移”——一个位移网格，使HTML向光标外扩散，带有颜色边缘/颗粒感
- “放大”——科幻扫描镜头放大HUD准星中的HTML图像，点击波纹使页面弯曲
- “字形雨”——落下的字形流点亮 HTML 区域，光标穿透处涌动

每个人的完整演示/视频：《https://canvasui.dev/components》。每个组件文档（道具、代码）位于“https://canvasui.dev/docs/components/”<slug>（烤肉箱，例如“液体”、“玻璃物体”、“火焰包裹”）。

## 如何安装/配置它

每个组件都包含**六种框架版本**（React 19、Solid 1.9、Preact 10、Vue 3.5、Svelte 5、原版TS）和**两种渲染器构建**（WebGL——默认，最广泛支持;WebGPU 通过 'vgpu'/WGSL，'-webgpu' 注册表后缀）。选择框架+渲染器一次;每个安装命令都是一致的。

通过 shadcn CLI 安装（如果项目中未使用，先运行 'npx shadcn@latest init'）：


```
npx shadcn@latest add @canvas-ui/<component>-<framework>
# WebGPU variant:
npx shadcn@latest add @canvas-ui/<component>-<framework>-webgpu
```


这会把源代码输入到“components/canvasui/”（Svelte：'src/lib/components/canvasui/'）。没有CLI可用吗？直接从组件文档页面复制源码——结果一样，因为无论哪种方式都没有包依赖关系。

使用方式就是对目标内容进行封装：


```tsx
import { Liquid } from "@/components/canvasui/Liquid";

<Liquid rainbow style={{ height: 480 }}>
  <YourContent />
</Liquid>
```


道具是按组件类型化且可选的;在具体规范行为之前，先查看文档页面的具体组件的道具表。

还有一个 Canvas UI MCP 服务器（“https://canvasui.dev/docs/mcp”），如果项目环境中有连接器，AI 助手可以直接安装组件。

## 在提出组件时需要标记的约束

- **实验性API**：完整的画布内html效果需要Chrome/Edge 140+，带有“#enable-experimental-web-platform-features”标志，或用于生产的域名注册起源试验令牌。其他地方则是干净的备选（普通 HTML，或仅 WebGL 覆盖版本）——提及这个退化路径，避免误认为是 bug。
- **运动灵敏度 / 减少运动**：这是GPU着色器效果，通常是光标或滚动反应——尊重“偏好减少运动”，并根据前端设计的“节约、刻意运动”指导，将效果排除在关键路径内容之外。
- **性能**：WebGL/WebGPU 画布具有实际的 GPU 成本;不要在一页上叠加多个效果，除非经过测试，否则不要在低功率或移动设备受限的目标上使用。
- **许可**：MIT + Commons 条款——商业产品罚款;只有将图书馆本身作为产品转售是受限的。
