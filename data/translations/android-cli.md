# Android CLI专员

此技能提供使用“android” CLI工具的说明。 该工具包括用于创建项目、运行应用程序、与设备交互以及管理CLI环境的各种命令。

# #安装

如果Android工具不在路径中，请安装它。 要安装，请运行以下命令：
Linux ： curl -fsSL https://dl.google.com/android/cli/latest/linux_x86_64/install.sh | bash
Mac Arm ： curl -fsSL https://dl.google.com/android/cli/latest/darwin_a
