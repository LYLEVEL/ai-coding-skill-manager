# 温馨治愈系 UI 设计规范 (Cozy Pastel UI Design)

本设计规范提炼自一套高度成熟的温润治愈系 UI 系统。
其设计语言的核心在于：**温暖大地色系 + 胶囊大圆角 + 物理按键立体感 + 柔和动效 + 几何与有机形状并存**。

## 1. 核心设计原则 (Design Principles)

1. **温润无锐角**：避免任何锋利的直角，所有交互元素和容器必须使用充沛的圆角（Pill 形状或平滑的 Organic Shape）。
2. **温暖的大地色调**：抛弃极简主义的冷白与纯黑。背景统一使用带有温度的羊皮纸色或奶油色；文字使用深浅不一的棕色系。
3. **物理触碰感**：主操作按钮应该像真实的玩具按键一样，拥有厚实的底部 3D 堆叠阴影，在点击时产生真实的“下压”物理反馈。
4. **克制的有机形态**：在弹窗、特殊卡片等大面积元素上，可以使用轻微不规则的 SVG 路径（如平滑的 Blob 形状）或手绘感边缘，打破死板的几何网格。

## 2. 设计 Token (Design Tokens)

### 🎨 色彩系统 (Color Palette)

*   **主背景 (Primary Bg)**: `#f8f8f0` (暖色米白/羊皮纸)
*   **内容区背景 (Content Bg)**: `rgb(247, 243, 223)` (奶油色，用于卡片、弹窗内部)
*   **主文字 (Primary Text)**: `#794f27` (深棕，用于标题或强调文本)
*   **正文文字 (Body Text)**: `#725d42` (中棕，用于普通正文)
*   **次级/禁用文字 (Muted Text)**: `#9f927d` / `#c4b89e`
*   **主色调 (Primary Accent)**: `#19c8b9` (薄荷青绿，用于主按钮或强调状态)
*   **焦点/警示高亮 (Focus/Highlight)**: `#ffcc00` (明亮且温暖的黄色)
*   **柔和边框 (Border)**: `#c4b89e` 
*   **3D 阴影色 (3D Shadow)**: `#bdaea0` (暖灰褐色，用于立体按键侧边)

### 🔤 字体系统 (Typography)

必须使用**圆体或极其柔和的无衬线字体**（如英文字体推荐 `Nunito`，中文字体推荐 `Noto Sans SC` 的柔和版本或圆体）。
*   **字重 (Font Weight)**: 严禁使用细体 (`weight < 400`)。正文推荐 `500`，标题及按钮文字推荐 `600` - `700`，大字号数字体推荐 `900`。
*   **字间距 (Letter Spacing)**: 正文微调 `0.01em`，按钮和标题 `0.02em` 以增加呼吸感。

### 🧊 阴影与深度 (Shadow & Depth)

*   **物理按键 3D 阴影** (仅用于 Primary 按钮等强交互元素)：
    `box-shadow: 0 5px 0 0 #bdaea0;`
*   **柔和悬浮阴影** (用于普通卡片或次级按钮)：
    `box-shadow: 0 3px 10px 0 rgba(61, 52, 40, 0.10);`

## 3. 核心组件规范 (Component Specs)

### 🔘 Button (按钮)
*   **形状**: 完全的胶囊形 (`border-radius: 50px`)。
*   **主按钮 (Primary)**: 使用背景色 `#f8f8f0` 与深棕文字。带有 3D 阴影 `0 5px 0 0 #bdaea0`。
    *   *Hover*: 阴影加深为 `6px`，元素上移 `translateY(-1px)`。
    *   *Active*: 阴影压缩为 `1px`，元素下压 `translateY(2px)`，模拟真实按压。
*   **次级按钮**: 不使用厚重的 3D 阴影，仅使用柔和的悬浮投影，避免视觉过载。
*   **焦点 (Focus)**: 使用 `outline: 2px solid #19c8b9; outline-offset: 2px;`。

### ⌨️ Input (输入框)
*   **形状**: 胶囊形 (`border-radius: 50px`)，默认边框厚度略大（如 `2.5px solid #c4b89e`）。
*   **聚焦 (Focus)**: 边框变为黄色 `#ffcc00`，并带有柔和的黄色外发光 `box-shadow: 0 0 0 3px rgba(255, 204, 0, 0.15)`。绝对不能使用冷蓝色作为焦点环。

### 🗂️ Card (卡片)
*   **形状**: 大圆角矩形 (`border-radius: 20px`)。
*   **背景**: 默认使用奶油色 `rgb(247, 243, 223)`，内部文字为中棕色。
*   **层次感**: 默认不依赖 Box-shadow 来区分层级，而是依靠背景色差或边框。可采用柔和的马卡龙色作为卡片背景，或使用纯 CSS 实现的波点 (Polka-dot) 径向渐变作为装饰墙纸。
*   **交互**: 悬浮时轻微上浮 `transform: translateY(-2px);`。

### 💬 Modal / Tooltip (弹窗与提示)
*   **弹窗 (Modal)**: 推荐使用 SVG `clip-path` 裁剪出一个平滑、不对称的有机气泡形状 (Organic Blob)，而不是常规的圆角矩形，以此增加界面的俏皮感和自然气息。
*   **气泡提示 (Tooltip)**: 圆角需达到 `16px`，指向箭头可使用小菱形或独立的圆点悬浮，呈现更具生命力的形态。

### ✅ Checkbox / Radio / Switch (选择控件)
*   **Radio (单选)**: 并非完美的正圆，而是采用**高度圆滑的方形**（如 `border-radius: 14px` 对于 `22px` 的控件）。
*   **状态切换动效**: 选中状态的中心图标（勾或圆点）出现时，应带有轻快的弹性缩放动画 (pop animation): `0% scale(0.4) -> 60% scale(1.2) -> 100% scale(1)`，耗时约 `0.15s`。
*   **Switch (开关)**: 轨道内部有 `inset` 内阴影 (`inset 0 2px 4px rgba(114, 93, 66, 0.15)`)，滑块本身没有任何外部投影，只通过边框和位置区分层级。

### 🎀 Title (标题横幅)
*   **设计**: 作为章节标题，可设计为带有立体折角的“飘带” (Ribbon) 样式。
*   **实现**: 采用燕尾裁剪 (`clip-path: polygon(...)`) 作为底端，辅以深色的三角形边框模拟 3D 折叠的阴影，正面叠加并使用微小的 `rotateX` 透视，创造如实体彩带般的视觉中心。

## 4. 视觉禁忌 (Forbidden Patterns)

为保持风格的纯粹性，开发与设计时**严格禁止**以下做法：

1.  🚫 **锋利直角**: 禁止在任何交互元素或容器上使用 `0px radius`。
2.  🚫 **死板纯黑/纯白**: 禁止使用纯黑 `#000` 或纯白 `#fff` 作为大面积背景或主文字色（必须向温暖的棕色、奶油色偏移）。
3.  🚫 **冷色调高亮**: 禁止使用系统默认的冷蓝色（如 `#0066ff`）作为 Input 焦点或按钮轮廓，必须换用暖黄色或薄荷绿。
4.  🚫 **滥用厚重阴影**: 3D 物理按键阴影（如下沉的像素级阴影）仅限于 Primary 主操作，如果在所有按钮或卡片上滥用，会导致界面失去轻盈感。
5.  🚫 **纤细字体**: 界面中任何文字（包括 Placeholder）的 `font-weight` 都不得低于 `400`。
6.  🚫 **冷灰背景**: 禁用任何偏蓝或中性的灰色背景，必须含有一定的暖黄/暖棕色值。
